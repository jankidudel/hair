Quick answer

Check the exact box for the comb you want. The Conair SD11GNX lists a wide-tooth thermal comb and a dual-row comb. The Conair SD6RN lists a detangling comb and a styling comb. Choose by the head you will use and the directions supplied with that model.

Choose the comb by the job you need it to do

If you are drawn to a box because it lists two combs, read the model’s instructions for each one. The Conair listings use different names even though both boxes include two combs and a bristle brush. Write down the job that led you to search, such as guiding a section while drying or wanting a specific tooth layout. Then match that job to the part the exact manual recommends. Give more weight to the comb you would use regularly than to the number of pieces in the box.

For example, a shopper who is looking specifically for the SD11GNX wide-tooth thermal comb should check that the listing names it. Another shopper comparing the SD6RN should look for the detangling comb and styling comb by name. Keeping the codes next to the attachment names avoids mistaking the different pieces for interchangeable ones when you compare two retailer tabs.

What to ask a seller before ordering

Send the seller the dryer model code and the name of the comb you want. Ask whether that part is supplied in the sealed package, and whether the product variant at checkout is the same code. If the retailer shows compatible accessories elsewhere on the page, find the actual in-box list or ask for a photo of what the box lists. Save the exact variant name for the order so you can compare it when the package arrives.

If you already own the dryer, begin with its model label and the replacement part. Check whether the part maker lists that dryer code, then check any fitting and use instructions it provides. A new dryer and a separate comb solve different purchase questions. Work out which one you need before you compare prices.

Before disposing of the packaging, compare the names and images in the manual with the heads supplied. If the attachment you counted on is missing, use the exact dryer code and part name when you contact the retailer instead of trying a similar-looking piece from another dryer.
