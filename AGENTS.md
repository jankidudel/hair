# Hair editorial rules

This is a hair appearance, grooming, styling, tools, and product-comparison site—not a health site.

Never create or publish medical or health content, including diagnosis, treatment, supplements, disease, hair-loss treatments, hormonal content, prescriptions, or medical claims. Keep advice focused on cosmetic appearance and ordinary grooming. New or edited Markdown under `frontend/content/` must pass `npm run content:check`; flagged language requires editorial review and revision before it is published.

Articles are Markdown source files with required front matter. Use the shared Angular article page—never add an Angular component per article. Interactive experiences and bespoke landing pages are Angular components, not custom Markdown blocks.
