<h1>Markdown Syntax Example</h1>
<p>This sample article exists to make the editorial workflow easy to see. A normal Markdown <a href="https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Howto/Markdown_in_MDN">link can point to another helpful resource</a>.</p>
<p><img src="https://images.unsplash.com/photo-1527799820374-dcf8d9d4a388?auto=format&#x26;fit=crop&#x26;w=1200&#x26;q=80" alt="A wooden hair brush on a light surface"></p>
<h2>A simple list</h2>
<ul>
<li>Write ordinary text.</li>
<li>Add a link with <code>[label](https://example.com)</code>.</li>
<li>Add an image with <code>![useful alt text](https://example.com/image.jpg)</code>.</li>
</ul>
