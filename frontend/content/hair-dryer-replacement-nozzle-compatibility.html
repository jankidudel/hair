Find the dryer model and match it against the replacement nozzle’s compatibility list. If the seller only gives a diameter, check the connection and the maker’s stated exclusions before buying. A similar shape is a reason to investigate, not proof of fit. The worked examples below use Shark parts because their pages print the exact model codes each nozzle fits.

Quick answer

Copy the model code from the dryer’s rating label and buy only a nozzle whose part page lists that exact code. If it is not listed, record no match yet and ask the maker; never force, tape or modify a nozzle to make it stay on.

Record four things before you search

Copy these from the dryer’s rating label and the manual, then fill in the last column from the part page you are considering.

Field Where to find it Your entry
Body model code Rating label on the dryer, not the box colour name Blank
Market Where it was sold; a code ending UK or EU can differ from a US code Blank
Connector type Manual: magnetic, shaped or locking, or slip-on Blank
Spare part code and its listed models The replacement part page Match, or no match yet

Only write “match” when your exact body code appears on the part’s list. Anything else is “no match yet”, which means ask the maker, not force the part on.

Identify the connection without forcing it

  • Magnetic: the nozzle holds by magnets and usually only fits the maker’s own system. Use the model list; diameter does not decide it.
  • Shaped or locking: the nozzle turns or clicks into a keyed outlet. Fit depends on that exact shape, so the model list decides.
  • Slip-on: the nozzle pushes over a round outlet. If the part maker publishes a fit range, measure the outlet’s outside where the collar sits; otherwise a diameter alone is unconfirmed.

Do not tape, pad or modify a nozzle to make it stay on. A loose or improvised fit can partly block the outlet or come off while hot.

Why the same brand is not enough

The three Shark examples above are all concentrators from one maker, yet none of them names the same bodies. The SpeedStyle part lists HD300-series codes, the FlexStyle part lists FlexStyle codes but not plain HD430, and the Pro Flex part lists HD500 and HD542 codes. A part that looks right on a product photo and carries the right brand name can still be for a different system. Read the list every time, even for a replacement of a part you already had.

When there is no match yet

  1. Search the dryer maker’s spare-parts page by your exact model code.
  2. If nothing is listed, contact the maker with the code from the rating label.
  3. If the missing part is a diffuser rather than a nozzle, use diffuser compatibility instead.
