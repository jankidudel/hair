These two UK Airwrap i.d. listings give you different attachments around the same named generation. The Straight+Wavy Ceramic Patina/Topaz kit lists a 40 mm barrel, Soft smoothing brush and Dryer+Flyaway smoother. The Vinca Blue/Topaz kit with Diffuser lists a Wave+Curl diffuser, Firm smoothing brush and Wide-tooth comb. Both list the main unit, a Fast dryer, a Conical Airwrap barrel, a Large round volumising brush, a Filter cleaning brush and a Presentation case. This guide lines the two boxes up by role so you can match the exact pack in a listing.

What both kits list

Both boxes share the main unit, Fast dryer, Conical Airwrap barrel, Large round volumising brush, Filter cleaning brush and Presentation case. The differences are in curling, smoothing and finishing: the 40mm barrel, Soft smoothing brush and Dryer+Flyaway smoother on one side; the Wave+Curl diffuser, Firm smoothing brush and Wide-tooth comb on the other. Dyson’s with-Diffuser page address uses “curly-coily”, so a listing may use either name.

If you are actually comparing generations rather than two i.d. packs, read Dyson Airwrap i.d. vs Complete Long. For how Dyson names kits more broadly, see how to choose a Dyson Airwrap.

Check the package shown by a seller

A box list tells you what a new kit contained. It doesn’t tell you what a seller still has. Match the colour and kit name first, then check each piece.

Worked case: you need the included diffuser. Only the Vinca Blue/Topaz with-Diffuser box lists the Wave+Curl diffuser. If a listing shows Ceramic Patina/Topaz, expect no diffuser from the box and ask the seller.

Worked case: you want the 40 mm barrel and see a conical one. Both boxes list a Conical Airwrap barrel, so a photo of it doesn’t tell you which kit you are looking at. Only the Straight+Wavy box lists the 40mm barrel. Ask to see it. Use the Used Multi-Styler Checklist with the With Diffuser pack to mark each piece and copy your questions for the seller.

Smoothing brushes are the easiest pieces to confuse in a photo. The Straight+Wavy box lists a Soft smoothing brush and the with-Diffuser box a Firm smoothing brush. Ask the seller which one is included, or for a photo that shows any name printed on it, rather than judging firmness from a picture. The same goes for the drying pieces: the Dryer+Flyaway smoother is listed only in the Straight+Wavy box.

Dyson also sells a refurbished Airwrap i.d. with Diffuser in Vinca Blue/Topaz. It is a separate package. Check its own listing rather than assuming it matches the retail kit.
