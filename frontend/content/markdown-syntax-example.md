# Markdown Syntax Example

This sample article exists to make the editorial workflow easy to see. A normal Markdown [link can point to another helpful resource](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Howto/Markdown_in_MDN).

![A wooden hair brush on a light surface](https://images.unsplash.com/photo-1527799820374-dcf8d9d4a388?auto=format&fit=crop&w=1200&q=80)

## A simple list

- Write ordinary text.
- Add a link with `[label](https://example.com)`.
- Add an image with `![useful alt text](https://example.com/image.jpg)`.

## A GFM table

| Markdown feature | What it becomes   |
| ---------------- | ----------------- |
| `## Heading`     | A section heading |
| `**Text**`       | **Bold text**     |
| `[Link](URL)`    | A normal link     |
